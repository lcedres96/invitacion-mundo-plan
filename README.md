# Invitación · Mundo Plan 20 años

Web de la fiesta de fin de año y 20 aniversario de Mundo Plan.

- **Cuándo:** viernes 11 de diciembre de 2026, de 21:00 a 02:00 h
- **Dónde:** Hotel Madero, Salón Montmartre (9° piso), Rosario Vera Peñaloza 360, Puerto Madero, CABA
- **Confirmación:** por WhatsApp desde la web

La página es un solo archivo (`index.html`) con las tipografías y el logo incluidos, así que no depende de servicios externos. `vista-previa.jpg` es la imagen que aparece al compartir el enlace.

Para cambiar el número que recibe las confirmaciones, buscá `WA_NUMBER` en `index.html`.
